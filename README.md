# Payment Center

> Halaman informasi metode pembayaran premium dengan desain dark modern.

## Fitur Utama

- ✅ **4 Metode Pembayaran**: QRIS, DANA, SeaBank, + Metode Lainnya
- ✅ **Modal Premium**: Glassmorphism dengan animasi smooth
- ✅ **Copy to Clipboard**: Dengan feedback visual dan toast notification
- ✅ **Responsive Design**: Mobile, tablet, dan desktop
- ✅ **Dark Theme**: Premium dengan aksen cyan
- ✅ **Proteksi Ringan**: Disable text selection, right click, dan drag

## Teknologi

- HTML5 Semantic
- CSS3 (Variables, Grid, Flexbox, Glassmorphism)
- Vanilla JavaScript (No Framework)
- FontAwesome 6 Icons
